# Safety Vision

Локальный MVP компьютерного зрения для контроля опасной зоны в реальном времени.

Система получает видео с веб-камеры, обнаруживает людей через YOLO и подаёт визуальное предупреждение, когда точка ног человека попадает внутрь заданной пользователем многоугольной опасной зоны.

## Облачная версия

Браузерный интерфейс находится в `web_app.py` и предназначен для Hugging Face Spaces. После развёртывания пользователю достаточно открыть ссылку, разрешить доступ к камере и включить её — терминал и локальная установка не нужны.

В облачной версии можно создать несколько профилей камер и нарисовать для каждой отдельную зону кликами по кадру результата. Профили MVP хранятся только в текущей сессии браузера. Кадры передаются на сервер для обработки. Не используйте конфиденциальное видео без разрешения организации.

## Возможности

- работа с веб-камерой или видеофайлом;
- интерактивная разметка опасной зоны;
- несколько профилей камер с отдельной зоной для каждого;
- детекция людей в реальном времени;
- счётчик людей и нарушений;
- визуальная и звуковая тревога;
- конфигурация в относительных координатах — зона переносится между разрешениями;
- опциональное подключение собственной PPE-модели для классов каски/жилета.

> Важно: стандартная модель YOLO умеет надёжно находить людей, но не распознаёт отсутствие каски или жилета. Для PPE-контроля нужен отдельный обученный файл весов `.pt`. Репозиторий не выдаёт имитацию за готовую функцию.

## Быстрый запуск

Требуется Python 3.10–3.12.

### Windows PowerShell

```powershell
git clone https://github.com/generke/safety-vision.git
cd safety-vision
py -m venv .venv
.venv\Scripts\python.exe -m pip install --upgrade pip
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe zone_editor.py --camera 0
.venv\Scripts\python.exe app.py --camera 0
```

Использование прямого пути к Python внутри `.venv` обходит ошибку PowerShell `ExecutionPolicy`, поэтому активировать окружение необязательно.

### macOS / Linux

```bash
git clone https://github.com/generke/safety-vision.git
cd safety-vision
python3 -m venv .venv
.venv/bin/python -m pip install --upgrade pip
.venv/bin/python -m pip install -r requirements.txt
.venv/bin/python zone_editor.py --camera 0
.venv/bin/python app.py --camera 0
```

При первом запуске Ultralytics автоматически загрузит стандартные веса `yolo11n.pt`.

## Управление

### Редактор зоны

- левая кнопка мыши — добавить точку;
- `Backspace` или `Z` — удалить последнюю точку;
- `R` — очистить;
- `S` или `Enter` — сохранить;
- `Esc` или `Q` — выйти.

### Мониторинг

- `Q` или `Esc` — выйти;
- `S` — сохранить кадр в `captures/`.

## Другие источники видео

```bash
python app.py --camera 1
python app.py --source path/to/video.mp4
python app.py --source "rtsp://user:password@camera/stream"
```

Не помещайте RTSP-пароли в репозиторий или `config.json`.

## PPE-модель

Положите собственные веса, например `models/ppe.pt`, и запустите:

```bash
python app.py --ppe-model models/ppe.pt
```

Названия классов модели должны содержать понятные обозначения вроде `helmet`, `no_helmet`, `vest`, `no_vest`. PPE-результаты выводятся отдельно; логика сопоставления СИЗ конкретному человеку требует доработки под классы выбранного датасета.

## Ограничения MVP

- это система предупреждения, а не сертифицированное средство безопасности;
- качество зависит от ракурса, света и перекрытий;
- звуковой сигнал может не работать в безголовой среде;
- для промышленного применения нужны журнал событий, роли, несколько камер и тестирование на реальном объекте.
